# 🛍️ Loja Online - Comércio

Uma loja online moderna e responsiva desenvolvida com HTML e CSS.

## 📋 Descrição

Este projeto é um exemplo de e-commerce com:
- Design moderno e intuitivo
- Interface responsiva para mobile e desktop
- Grid de produtos com 8 itens de diferentes categorias
- Sistema de filtros por categoria
- Carrinho de compras visual
- Banner de destaque
- Footer com múltiplas seções

## 🚀 Como visualizar

### Opção 1: GitHub Pages (Recomendado)
Se você ativar GitHub Pages no seu repositório, a página será acessível em:
```
https://dansilva33-prog.github.io/Primeiro-projeto/
```

**Para ativar:**
1. Vá para **Settings** do repositório
2. Role até **Pages** (no menu lateral)
3. Em "Source", selecione a branch `main` (ou `master`)
4. Clique em **Save**
5. Aguarde alguns minutos e acesse o link acima

### Opção 2: Visualizar no GitHub
Você pode clicar no botão "Preview" diretamente:
- Abra o arquivo `index.html` no GitHub
- Clique em "Preview" ou acesse: https://github.com/Dansilva33-prog/Primeiro-projeto/blob/main/index.html

### Opção 3: Baixar e abrir localmente
1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` em seu navegador
